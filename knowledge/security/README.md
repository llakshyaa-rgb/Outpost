# Local knowledge packs

OUTPOST indexes this directory automatically. Add trusted, licensed Markdown, Markdown, YAML or text references here.

Suggested structure:

- `web/` — web application security checklists
- `mobile/` — Android and mobile application security references
- `network/` — network hardening and troubleshooting
- `forensics/` — defensive incident response and file-analysis references
- `methodology/` — authorized assessment methodology

Keep the original project name, source URL, license, and retrieval date in each imported pack. Do not place secrets, private customer data, or material you are not allowed to redistribute here.
